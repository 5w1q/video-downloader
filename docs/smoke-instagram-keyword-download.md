## 0. 功能清单（须覆盖）

| 能力 | UI / 行为 | 冒烟是否覆盖 |
|------|-----------|--------------|
| 关键词搜索 | 输入框，max 200 | ✅ |
| 最多下载条数 | 1–50，冒烟固定 2 | ✅ |
| 播放量 ≥ | 0=不限 | ✅ F0/F1 |
| 点赞 ≥ | 0=不限 | ✅ F0/F1 |
| 评论 ≥ | 0=不限（IG 专有硬筛） | ✅ F0/F1 |
| 发布日期 | 不限 / **近 24 小时** / 近一周 / 近一月 / **近一年** / 指定日期 | ✅（含 year） |
| 保存到浏览器 | 逐文件 | ✅ |

## 1. 固定参数

| 项 | 值 |
|----|-----|
| 关键词 | `AI` |
| 最多下载条数 | `2` |
| 跳过已下载 | **勾选** |
| 每条间隔（秒） | `1` |
| 环境 | 已配置 `APIFY_TOKEN`；浏览器允许下载 |

**阈值两档：**

| 档位 | 播放量 ≥ | 点赞 ≥ | 评论 ≥ |
|------|----------|--------|--------|
| F0 不限 | 0 | 0 | 0 |
| F1 阈值 | `10000` | `5000` | `100` |

> F1 可按实搜结果微调；长期空结果时可临时降低并在备注标明。

**发布日期：**

| 值 | UI | 过滤方式 |
|----|-----|----------|
| `all` | 不限 | 不滤日期 |
| `today` | 近 24 小时 | 本地 `upload_date == 今日` |
| `week` | 近一周 | 本地近 7 天 |
| `month` | 近一月 | 本地近 30 天 |
| `year` | 近一年 | 本地近 365 天 |
| `date` | 指定日期 | 本地按 `taken_at_date` 滤 |

**保存：** 浏览器 / ZIP

> 「最多下载 2」指每条用例最多下载 2 个视频，不等于只跑 2 个用例。

## 2. 通过标准

- [ ] 搜索+下载日志完整；结束有汇总
- [ ] 条数 ≤ 2
- [ ] 列表：标题、播放、点赞、评论；有日期则展示
- [ ] F1 命中项满足播放/点赞/评论
- [ ] 日期档结果符合对应区间（近 24h / 7 天 / 30 天 / 1 年 / 指定日）
- [ ] 浏览器 / ZIP 交付正确
- [ ] 跳过复验通过
- [ ] 缺 Key 时有可读错误

> 说明：近 24 小时/指定日可能 0 条，属可接受；须有明确空结果提示，而非前端卡死。

## 6. 已知限制

- 点赞/评论/播放/日期均为本地过滤；召回池偏相关热门时，近 24 小时等档可能更易空。
- 「近 24 小时」按本地日历日过滤；缺 `taken_at_date` 的条目在相对档可能仍出现。
- 需 `APIFY_TOKEN` 与 Actor 额度；Token 无效/额度不足会直接失败。
- 下载优先使用搜索结果中的 CDN `video_url`（页面 URL 仍用于展示与「跳过已下载」）；无 `video_url` 时回退 yt-dlp 抓页面（常需 `INSTAGRAM_COOKIEFILE` / 浏览器 Cookie）。
- 跳过/ZIP 行为与其它平台共用 bulk 流水线。
- 「保存到浏览器」与「打包 zip」最终都进浏览器下载；差异是逐文件 vs 先打包。
