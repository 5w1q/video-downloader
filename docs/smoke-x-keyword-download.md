## 1. 固定参数

| 项 | 值 |
|----|-----|
| 关键词 | `AI` |
| 最多下载条数 | `2` |
| 跳过已下载过的链接 | **勾选**（默认） |
| 每条间隔（秒） | `1` |
| 环境 | 前端可达后端；已配置 `APIFY_TOKEN`；浏览器允许下载 |

**互动阈值两档（F0 / F1）：**

| 档位 | 点赞 ≥ | 转发 ≥ | 评论 ≥ |
|------|--------|--------|--------|
| F0 不限 | 0 | 0 | 0 |
| F1 阈值 | `5000` | `100` | `50` |

> F1 数值可按实搜结果微调；原则是「明显高于不限、仍可能出结果」。若长期空结果，可临时降到 1000/20/10 并在备注标明。

**发布日期：**

| 值 | UI |
|----|-----|
| `all` | 不限 |
| `today` | 今日 |
| `week` | 近一周 |
| `month` | 近一月 |
| `date` | 指定日期（须选具体日） |

**保存方式：** 浏览器（不勾 ZIP）/ ZIP（勾选「打包 zip」）

> 「最多下载 2」指每条用例最多下载 2 个视频，不等于只跑 2 个用例。

## 2. 通过标准

- [ ] 日志有搜索与下载进度；结束有成功/跳过/失败汇总
- [ ] 处理条数 ≤ 2
- [ ] 列表展示：标题、点赞、转发、评论；有日期则展示
- [ ] F1：命中项满足点赞/转发/评论阈值（以列表为准）
- [ ] 日期筛选：发布日落在对应区间
- [ ] 浏览器模式：下载目录出现文件
- [ ] ZIP：可下载；解压文件数 ≈ 成功数
- [ ] 跳过开启时，同 URL 复跑计为跳过
- [ ] 无 `APIFY_TOKEN` 时应有明确失败提示（非白屏）

> 说明：今日/指定日在候选池内可能 0 条，属可接受；应看到明确空结果提示，而非前端卡死。

## 6. 已知限制

- 依赖 Apify 额度与 Actor 稳定性；结果非实时全量。
- 默认仅视频（`filter:videos`）；前端无关闭开关。
- 「评论」= X 回复数（`min_replies`）。
- 今日/高阈值易空；空结果算可接受，须有明确提示。
- 跳过依赖服务端状态；换机/清状态后行为变化。
- ZIP 条数=2 时通常单卷。
- 「保存到浏览器」与「打包 zip」最终都进浏览器下载；差异是逐文件 vs 先打包。
