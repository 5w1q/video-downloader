## 1. 固定参数（除非用例另有说明）

| 项 | 值 |
|----|-----|
| 关键词 | `AI` |
| 最多下载条数 | `2` |
| 跳过已下载过的链接 | **勾选**（默认） |
| 每条间隔（秒） | `1`（加速；默认 2 也可） |
| 环境 | 前端可访问后端；浏览器允许下载 |

**播放量 / 点赞两档（下文简称 F0 / F1）：**

| 档位 | 播放量 ≥ | 点赞 ≥ |
|------|----------|--------|
| F0 不限 | 空 / 0 | 空 / 0 |
| F1 阈值 | `10000` | `5000` |

**发布日期：**

| 值 | UI |
|----|-----|
| `all` | 不限 |
| `today` | 今日 |
| `week` | 近一周 |
| `month` | 近一月 |
| `date` | 指定日期（须选具体日，建议选近 30 天内有结果的一天） |

**保存方式：**

| 模式 | 操作 |
|------|------|
| 浏览器 | 「保存到浏览器下载目录」；**不**勾选「打包 zip」→ 成功条目应触发逐文件下载 |
| ZIP | 勾选「打包 zip」→ 结束后出现 ZIP/分卷，点「下载」或备用链接 |

> 「最多下载 2」指每条用例最多下载 2 个视频，不等于只跑 2 个用例。

## 2. 通过标准（通用）

- [ ] 日志出现搜索与下载进度；结束有「成功 / 跳过 / 失败」汇总
- [ ] 实际处理条数 ≤ 2；进度分母为找到的条数（≤ 2）
- [ ] 列表项展示标题、播放、点赞；有日期时展示发布日
- [ ] F1 时：命中项播放 ≥ 1万、点赞 ≥ 5000（以列表展示为准）
- [ ] 日期筛选时：命中项发布日落在对应区间（今日 / 近 7 天 / 近 30 天 / 指定日；时区按服务端东八区）
- [ ] 浏览器模式：浏览器下载目录出现视频文件
- [ ] ZIP 模式：可下载 zip；解压后文件数与成功数一致（跳过/失败不计入）
- [ ] 默认跳过开启时：对已成功记过的同一 URL 再次下载应计为「跳过」

> 说明：今日/指定日在候选池内可能 0 条，属可接受；应看到明确空结果提示，而非前端卡死。

## 3. 推荐用例矩阵（主冒烟）

### 3.1 主路径：搜索并下载

| ID | 筛选 | 日期 | 保存 | 操作 | 期望要点 |
|----|------|------|------|------|----------|
| YT-01 | F0 | 不限 | 浏览器 | 搜索并下载 | ≤2 条成功/跳过；逐文件进浏览器下载目录 |
| YT-02 | F0 | 不限 | ZIP | 搜索并下载 | 出现 ZIP 区；下载一次成功；链接一次性 |
| YT-03 | F1 | 近一周 | 浏览器 | 搜索并下载 | 命中项满足阈值+近 7 天；或空结果提示可降阈值 |
| YT-04 | F1 | 近一月 | ZIP | 搜索并下载 | 同 YT-03 + ZIP |
| YT-05 | F0 | 今日 | 浏览器 | 搜索并下载 | 有结果则均为今日；无结果则提示非今日发布/可改不限 |
| YT-06 | F0 | 近一周 | ZIP | 搜索并下载 | 日期落在近一周 |
| YT-07 | F1 | 指定日期 | 浏览器 | 选具体日 → 搜索并下载 | 命中项发布日=所选日；未选日见 YT-B1 |
| YT-08 | F0 | 近一月 | 浏览器 | 搜索并下载 | 覆盖「近一月」+ F0 + 浏览器 |

**与原计划对应：**

- 两种筛选：YT-01/02（F0）、YT-03/04/07（F1）
- 四种日期：YT-05 今日、YT-03/06 近一周、YT-04/08 近一月、YT-07 指定日
- 两种保存：矩阵已交叉浏览器 / ZIP
- 默认跳过：全部主用例保持勾选；跳过验证见 YT-S1

若时间极紧，**最低集**可只跑：`YT-01、YT-02、YT-03、YT-05、YT-07、YT-S1、YT-P1`。

## 4. 补充用例

| ID | 场景 | 步骤 | 期望 |
|----|------|------|------|
| YT-P1 | 仅预览再下载 | 填 AI、F0、不限、条数 2 →「仅预览结果」→ 确认列表 → 选保存方式 →「下载（N）」 | 预览不触发下载；下载阶段不再重新搜索；条数与预览一致 |
| YT-P2 | 预览后改条件 | 预览成功后改关键词/阈值/日期 | 「下载」态取消，需重新预览或搜索并下载 |
| YT-S1 | 跳过已下载 | 用 YT-01 同条件再跑一次（跳过仍勾选） | 已成功 URL 日志为跳过；成功数不重复涨（或 skip 增加） |
| YT-S2 | 关闭跳过 | 取消「跳过已下载」后对同一批再下 | 不再因「已下载」跳过（仍可能因网络/平台失败） |
| YT-B1 | 指定日期未选日 | 发布日期=指定日期，日期留空 → 搜索/下载 | 错误提示需选择筛选日期 |
| YT-B2 | 空关键词 | 关键词空 | 主按钮不可点 / 无法发起 |
| YT-B3 | 阈值过高空结果 | F1 + 今日（或极严组合） | 明确错误/日志：扫描 N 条、因日期或阈值跳过；可降阈值或改日期 |
| YT-B4 | 取消 | 搜索并下载进行中点「取消」 | 前端停止收流；日志提示已取消（当前条服务端可能仍在处理） |
| YT-B5 | 未达标展示 | F1 + 近一周 → 仅预览 | 若有日期命中但未达播放/点赞，下方琥珀色未达标列表可出现 |
| YT-Z1 | ZIP 一次性 | YT-02 下载 ZIP 后再次点同一链接 | 第二次应失败或不可用（与产品文案一致） |

## 6. 已知限制（测前知悉）

- 搜索依赖 yt-dlp / YouTube，结果不稳定；「今日」易空。
- 跳过依赖服务端已下载状态 + 可选验文件；换机器/清状态后跳过行为会变。
- ZIP 分卷在文件较大时才会出现；条数=2 时通常单卷。
- 「保存到浏览器」与「打包 zip」最终都进浏览器下载；差异是逐文件 vs 先打包。
